# Reporting issues and proposing corrections

[Home](README.md) · [한국어](#한국어)

This repository publishes a fixed evaluation evidence release. Use [GitHub Issues](https://github.com/tenconic-ai/tenconic-memory-evaluation/issues) for calculation problems, unclear methodology, attribution questions, or proposed corrections.

For reproducibility reports, include the release tag, Python version, command, relevant record IDs, and expected versus observed behavior. Share only public information; do not attach credentials, private retrieval contexts, or omitted answer bodies. For a sensitive disclosure concern, report the affected file and record ID without reproducing the sensitive text.

For a calculation-code pull request, explain the effect on existing scores and run the focused tests and offline score checks in the README. Preserve historical evidence and disclose any correction that changes published results. A contribution does not change the licenses of third-party materials. Proposed changes remain subject to maintainer review; this repository does not promise a support response time.

## 한국어

계산 오류, 방법론 설명, 출처·이용 조건, 정정 제안은 [Issues](https://github.com/tenconic-ai/tenconic-memory-evaluation/issues)에 남길 수 있습니다. 재현 문제에는 릴리스 태그, Python 버전, 실행 명령, 해당 문항 ID와 기대·실제 결과를 적어 주십시오. 공개 정보만 제공하고 자격 증명·비공개 검색 문맥·제외된 답변 본문은 첨부하지 마십시오. 민감한 공개 내용의 문제가 있으면 해당 값을 반복하지 말고 파일과 문항 ID로 알리십시오.

계산 코드 변경을 제안할 때에는 기존 점수에 미치는 영향을 설명하고 README의 테스트·오프라인 점수 검사를 실행하십시오. 과거 기록을 보존하고 결과가 달라지는 정정은 명시해야 합니다. 기여로 제3자 자료의 라이선스가 바뀌지 않으며 변경 제안은 관리자의 검토를 거칩니다.
